Skeleton processing (2026-11-22): the Commons file host (upload.wikimedia.org) rate-limited this server's shared egress IP with HTTP 429 for the whole build (GETs return a 3,410-byte error page; HEAD still returns 200 — a HEAD 200 does NOT mean the limit cleared). 8 of 11 parts were rescued from the Wayback Machine (identical files, sizes verified against the Commons metadata): vertebral column, pelvis, femur, humerus, scapula, tibia, fibula, patella. The skull has no Wayback capture and the rib-cage capture is truncated (5,242,880 of 11,641,100 bytes — unusable), so both were assembled from the same BodyParts3D data in the DBCLS archive: the rib cage is the FMA7480 compound (24 ribs + 14 costal cartilages + manubrium + body of sternum + xiphoid = 41 primitives, range-downloaded one entry at a time from BodyParts3D_2.0_obj_95.zip via its central directory + HTTP Range) and the skull is 23 primitives (22 cranial + facial bones + the hyoid, FMA52734–FMA54738, FMA9710). The 2.0 OBJs are the same whole-body MRI dataset, so they sit in the same coordinate frame as the Commons STLs — verified by bounds (rib 3 at Z 1256–1358, sternum at Y −207..−165 in front of the column, manubrium above the sternum body). The limb files are BILATERAL (both sides in one file — femur X ±150, humerus X ±240), so no mirroring was needed. An NIH 3D skull ("Skull and Eyes – Visible Human Male", 3DPX-020591, CC-BY) was downloaded as a fallback and aligned by hand (eye components dropped, scaled cm→mm, seated on C1), but it sat ~130 mm too far back — the NIH frame is pitched relative to BodyParts3D — and was NOT used once the DBCLS skull assembled correctly. Per part: weld → drop fragments (relative rule: < min(1,500, max(150, 2% of largest component)) — an absolute 1,500 cut deleted the whole fibula, 1,146 faces/side, on the first pass) → decimate to target (skull 45.5k, spine 30k, rib cage 38.9k, pelvis 10k, scapula 18k, humerus 6k, femur 5k, tibia 3k, fibula 2k, patella 600) → Taubin-smoothed (18 iterations). EXCEPTION: Taubin DIVERGES on the DBCLS 2.0 OBJs (raw non-manifold meshes) — frontal bone Z-min 1529 → 1204, sphenoid 1489 → 580 after 18 iters, i.e. long spikes hanging off the skull — so the skull primitives skip Taubin (diagnosed per-primitive; the ribs, which are clean, keep it). Map BodyParts3D (X right, Y anterior-posterior, Z up) to three.js (X right, Y up, Z anterior): anterior is −Y in BodyParts3D, proven by the patella sitting in front of the femoral condyles. Centred + normalised (max extent 2.0) → GLB (2.7 MB, 159k faces, 10 parts). Orientation verified visually before labelling: front view shows the eye sockets facing the viewer, side view shows the face forward with the skull seated on the cervical spine, the S-curve of the spine, and the ribs sloping down from spine to sternum. Label anchors snapped to the surface (nearest-vertex). Motion is 'sway' — a slow presentation motion, since a skeleton neither beats nor breathes. Honest gaps: the clavicle download never cleared the 429 (no Wayback capture) and BodyParts3D publishes no radius/ulna, hand or foot bones on Commons, so the explorer shows the skeleton without clavicles, forearms, hands or feet — the caption says so.

Muscle processing (2026-11-23): no muscle STL exists on Wikimedia Commons (searched `filetype:stl muscle` — 0 hits; Commons holds only 2D BodyParts3D renders), so both heads of the right biceps brachii were taken from the same BodyParts3D dataset as the skeleton — element files FJ1512 (short head, FMA37682) + FJ1478 (long head, FMA37683) from `isa_BP3D_4.0_obj_99.zip` (136 MB, dbarchive.biosciencedbc.jp; the BP9154/BP8817 representation IDs map to the FJ file IDs via `isa_element_parts.txt`). License is CC BY 4.0 International per the dataset README (updated 2025-02-25; attribution "BodyParts3D, © The Database Center for Life Science licensed under CC Attribution 4.0 International") — note the 2011 OBJ headers still print the old CC BY-SA 2.1 Japan text. Welded (1,739 → 932 verts short head), dropped fragments < 150 faces (short head 1,842 of 1,856 kept; long head 1,416 of 1,426), no decimation needed (3,258 faces total). Taubin check: short head drift 3.6 mm (kept); long head drift 9.5 mm — DIVERGED, so the long head ships unsmoothed (same failure mode as the DBCLS 2.0 skull primitives, 2026-11-22). Mapped (x, z, −y), centred + normalised → GLB (60 KB). Orientation verified visually before labelling: origins at top (+Y, two tendons splitting apart), common tendon at bottom (−Y), anterior faces +Z, long head lateral — consistent with a right arm in anterior view. Label anchors snapped to the surface (nearest-vertex; `anchors-muscle.py` + marker overlay). Motion is 'contract' (new AnatomyModel3D mode): a slow shorten-and-bulge cycle, one curl per ~4 s, standing in for the contraction the 2D lab demonstrates — the caption says so honestly, since the mesh is a static segmentation. Honest gap: BodyParts3D publishes no fibre or tendon detail, so the model shows smooth bellies and tendons, not fibre bundles.

Neuron processing (2026-11-21): the Commons STL download was blocked by HTTP 429 from upload.wikimedia.org (shared egress IP rate-limited, same as the brain run), so the mesh was fetched instead as NIH 3D's GLB conversion of the same file via the 3d.nih.gov API (the /api/submissions/{id}/runs/{run}/output-files/{file} endpoint, which redirects to a presigned S3 URL — direct S3 links 403). The conversion is the "edited for printability" variant (3DPX-000529, remeshed/cleaned/extruded from 3DPX-000142): 7.1M verts / 2.38M faces in the 200 MB source GLB. Welded first (7.15M verts → 1.22M shared), dropped 802k faces of fragments < 1,500 faces (12,869 components in the extrusion soup), decimated to 130k faces, Taubin-smoothed (18 iterations), smooth normals, centred + normalised → GLB (2.4 MB). The un-extruded original (3DPX-000142, 36 MB GLB) was also tried and rejected: its thinner tubes collapse into a spike fan under decimation, and its 1,697 components are mostly sub-1,500-face fragments. Orientation verified visually before labelling: soma = the dense blob at low X / low Y, dendritic arbor = the broad fan in the Y–Z plane, axon = the single long thin process leaving the soma toward low Y / high Z (verified by tracing vertices along the soma→tip segment). Label anchors snapped to the surface (nearest-vertex to each target point). Motion is a faint heartbeat-style pulse, standing in for the firing rhythm — the caption says so honestly, since a neuron does not beat. Note: quadric decimation leaves some long thin triangles across the arbor (visible as faint filaments in flat orthographic renders); they read as fine branches in the shaded viewer, so the mesh ships as-is — see the run log for the comparison.

Brain processing (2026-11-20): the Commons STL download was blocked by HTTP 429 from upload.wikimedia.org (shared egress IP rate-limited; Retry-After 120 s, still 429 after the wait), so the mesh was fetched instead as NIH 3D's GLB conversion of the same file via the 3d.nih.gov API — same Nevit Dilmen model, same license. Welded first (STL soup: 3.83M verts → 659k shared), decimated to 110k faces, dropped 194 fragments < 1,500 faces (1,430 faces; lungs precedent), kept one 2,504-face interior piece inside the main volume, Taubin-smoothed (18 iterations), smooth normals, rotated +90° about Y so anterior faces +Z, centred + normalised → GLB (2.6 MB). Orientation verified visually before labelling: +Z is anterior (frontal pole, narrower than the occipital end), anatomical left/right = ±X, cerebellum posterior-inferior under the occipital lobe, brainstem stalk descending posteriorly (upper spinal cord included, down to y = −1). Label anchors snapped to the surface (nearest-vertex to each target point). Motion is a faint heartbeat pulse (~70 bpm), like the heart explorer.

Liver processing (2026-11-19): single component, 60k faces — no decimation
needed; merged vertices, Taubin-smoothed (18 iterations), smooth normals,
centred + normalised → GLB (1.1 MB). Orientation verified visually before
labelling: +Z is anterior (smooth diaphragmatic surface, falciform ligament),
anatomical right = −X (big lobe), left = +X (tapering point). Label anchors
verified against renders from six sides plus a marker overlay: the fossa and
porta hepatis anchors were snapped to the surface after first floating off
it. The gallbladder is not part of the mesh — it sits in the fossa, which the
explorer labels. Motion is a breathing pulse (the liver rides the diaphragm).

Airway processing (2026-11-17): kept all 10 components (44k faces, no
decimation needed), merged vertices, smooth normals, rotated −21.2° about X
to straighten the scan's lean to anatomical upright, centred + normalised
→ GLB (1.0 MB). Orientation verified visually: front (+Z) is anterior —
the C-shaped cartilage rings wrap the front; the flat membranous wall
faces posterior. Note: no openly licensed trachea + bronchial-tree model
exists on Commons (the Visible Human bronchi files are fragmented ring
pieces, checked and rejected), so the explorer shows the trachea itself,
which ends right at the carina.

Lungs processing (2026-11-16): dropped fragments < 1,500 faces, decimated to
110k faces, re-welded, Taubin-smoothed (18 iterations), smooth normals,
exported as GLB (2.6 MB). Anatomical right = model −X (three lobes),
left = +X (cardiac notch) — verified visually before labelling.

Processing applied (2026-11-16): STL → merged vertices, one subdivision pass,
smooth vertex normals, centred and normalised, exported as GLB (2.1 MB).
